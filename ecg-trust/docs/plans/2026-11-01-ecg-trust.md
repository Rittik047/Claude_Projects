# ecg-trust Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a reproducible, tested Python package that trains and evaluates a 12-lead ECG superclass classifier on PTB-XL. It must quantify when the model can be trusted (calibration, conformal abstention, subgroups, noise robustness, external validation, a GE 12SL comparison) and serve the model through an API and a demo.

**Architecture:** A `src/`-layout package `ecgtrust`. Its stages communicate through files on disk:
- raw data → a cached `.npy` signal array plus a metadata parquet;
- model checkpoints → stored predictions (`.npz`);
- calibrators and conformal thresholds;
- JSON and Markdown reports.

Each stage is a CLI subcommand driven by `configs/default.yaml`. Internal and external test evaluation are locked behind a freeze manifest.

**Tech Stack:**
- Python ≥ 3.11 (container: 3.13)
- numpy, pandas (+pyarrow), scipy, scikit-learn, wfdb, PyTorch (CPU)
- PyYAML, matplotlib
- FastAPI + uvicorn, Streamlit
- pytest, ruff, httpx

**Spec:** `ecg-trust/docs/specs/2026-11-01-ecg-trust-design.md` (approved 2026-11-01). Read it before starting any task.

**Data sources**
- Mirror base URL: `https://physionet-open.s3.amazonaws.com/`.
- Dataset versions (pinned):
  - `ptb-xl/1.0.3`
  - `ptb-xl-plus/1.0.1`
  - `ecg-arrhythmia/1.0.0`
- Every downloaded file must be verified against that dataset's `SHA256SUMS.txt`.

**Task definition**
- Classes, in this exact order: `CLASSES = ("NORM", "MI", "STTC", "CD", "HYP")`.
- Lead order, in this exact order: `LEADS = ("I","II","III","aVR","aVL","aVF","V1","V2","V3","V4","V5","V6")`.
- Model input: 12 × 1000 float32 in mV, at 100 Hz (10 s).

**Splits and the test lock**
- `train` = folds 1–8.
- Fold 9 is split 50/50 **by patient** into `val_select` and `val_calib` (seed 0).
- `test` = fold 10.
- `external` = `ecg-arrhythmia`.
- `test` and `external` predictions may be computed only through `ecgtrust evaluate`. That command requires a valid freeze manifest and logs each run. A second run is refused.

**Analysis constants**
- Seeds `[0, 1, 2]`.
- Conformal α ∈ `{0.05, 0.10}`.
- Bootstrap: 2,000 patient-level resamples, 95 % percentile CI.
- ECE: 15 equal-mass bins.
- SNR grid: `[24, 18, 12, 6, 0, -6]` dB.
- Age bands: `<40, 40–59, 60–79, 80–89, >89`. Age code `300` → `>89`.
- External classes with < 100 positives are reported as `"insufficient"`.

**Compute and commits**
- CPU only. No GPU code paths. `torch.set_num_threads(4)`.
- Commit messages: imperative subject line. End every commit with these two lines:

**Required wording**
- README and MODEL_CARD must contain the spec §1 non-claims verbatim in substance: not a medical device; labels are a noisy reference; conformal guarantees are marginal under exchangeability; subgroup results are descriptive.
- Attribution: CC BY 4.0 citations for PTB-XL, PTB-XL+ and `ecg-arrhythmia` in README.

## Review Focus

1. **Interrupted or corrupt download.** Proxy cut-offs truncate files mid-transfer, and a rerun may find a half-written or corrupted cached file. Expected: resume via HTTP Range, re-verify SHA-256, and re-download on mismatch, never silently accept. Test added to Task 2.
2. **Malformed external records.** Some `ecg-arrhythmia` records may have flatline/all-zero leads, NaNs, or `Age: Unknown` / `Sex: Unknown`. Expected: flag and exclude with a logged reason, demographics map to `"unknown"`, and nothing crashes. Tests added to Task 6.
3. **API input in the wrong layout or units.** Arrays may arrive as (T, 12) instead of (12, T), or in µV. Expected: transposed input is rejected with a 422 that says to transpose; a median |amplitude| > 20 mV raises a quality warning (`"possible_unit_error"`). Tests added to Task 21.
4. **API input at other sampling rates** (250 or 360 Hz, not only 100/500). Expected: generic rational resampling to 100 Hz and centre-crop or zero-pad to 10 s; rates below 100 Hz are rejected. Test added to Task 21.
5. **Classes with very few positives in a calibration set or subgroup.** Expected: the conformal threshold becomes `inf`, so the label is always `"refer"`; subgroup metrics read `"insufficient"`; no crash and no NaN in reports. Tests added to Tasks 15 and 16.

### Task 15: Label-conditional conformal abstention

**Files:**
- Create: `src/ecgtrust/calibrate/conformal.py`
- Test: `tests/test_conformal.py`

**Interfaces:**
- Produces:
  - `@dataclass ConformalThresholds(q_present: np.ndarray, q_absent: np.ndarray, alpha: float)`. Shapes are (5,); values may be `inf`.
  - `fit_conformal(p: np.ndarray, y: np.ndarray, alpha: float) -> ConformalThresholds`.
  - `decide(p: np.ndarray, thr: ConformalThresholds) -> np.ndarray`: dtype `<U7`, values `"present" | "absent" | "refer"`, shape (N, 5).
  - `coverage(y, p, thr) -> dict`: `{"cov_pos": (5,), "cov_neg": (5,), "refer_rate": (5,), "acc_non_referred": (5,)}`.

Algorithm (Mondrian split conformal, run independently per class c):
```
scores_pos = 1 - p[y==1, c];  scores_neg = p[y==0, c]
q(scores) = sorted(scores)[ceil((n+1)(1-alpha)) - 1]  if ceil((n+1)(1-alpha)) <= n  else +inf
set(x) = {present if 1-p<=q_present} ∪ {absent if p<=q_absent}
decision = present if set=={present}; absent if set=={absent}; else refer   # empty or both → refer
```
